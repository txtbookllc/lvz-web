Windows 螢幕放大功能，以及 Low Vision Zoom 的定位

選擇放大鏡

哪一款是 Windows 最好用的螢幕放大鏡？

沒有單一「最好」的答案——這取決於您的需求，而正確的第一步是免費的。每台 Windows 電腦都已內建Windows Magnifier（放大鏡）（按下 Windows key + Plus 即可啟動）；對許多人來說已經夠用。如果您需要螢幕朗讀、非常高的放大倍率、色彩濾鏡或點字功能，像ZoomText或SuperNova這樣完整的輔助科技套件才是正確的類型。如果您想要的是平滑、沉穩、能跟隨游標移動的縮放功能，且不需要設定，Low Vision Zoom正是為這種情況打造的，一次性只需 $9.99。由於放大需求因人而異，購買前請先試用任何一款。請參閱我們的誠實比較。

Windows Magnifier 有沒有替代方案？

有的。除了 Microsoft 內建的 Windows Magnifier 之外，Windows 上的第三方放大鏡還包括 ZoomText 和 SuperNova（具備語音與閱讀工具的完整低視能套件）、免費的 Magnifixer，以及 Low Vision Zoom，一款專注於平滑、以游標為中心縮放的小型 $9.99 工具。人們通常在想要更流暢的操作感受、以滑鼠指標為中心的縮放，或內建工具沒有提供的語音與色彩功能時，才會尋找替代方案。哪一種替代方案合適，取決於您需要上述哪些功能——比較頁面會將它們並列呈現。

有沒有比 ZoomText 便宜的替代方案？

這取決於您依賴 ZoomText 的哪些功能。ZoomText 是一套完整的低視能軟體，具備語音、文件閱讀器、豐富的色彩與對焦強化功能，以及非常高的放大倍率，通常以年度授權方式銷售。如果您會用到那些閱讀與強化功能，誠實地說，較便宜的工具無法取代它們。如果您主要想要能跟隨游標的平滑放大功能，Low Vision Zoom 專門做這一件事，一次性只需$9.99——但它沒有語音、沒有閱讀功能、沒有色彩濾鏡，最高只能放大到 5×。Windows Magnifier 同樣是免費的，而且比許多人以為的更強大。

Low Vision Zoom 會朗讀文字嗎？

不會。Low Vision Zoom 僅提供放大功能。它沒有文字轉語音、沒有文件閱讀器，也沒有螢幕報讀功能。如果您需要螢幕朗讀，可以考慮ZoomText Magnifier/Reader、語音或螢幕報讀版本的SuperNova，或是 Windows 內建的Narrator，它是免費的。

Low Vision Zoom 與內建的 Windows Magnifier 有什麼不同？

Windows Magnifier 是免費、內建且功能完整的，許多人應該先試試它。Low Vision Zoom 的不同之處在於操作手感，而不是功能數量。它的縮放是連續的，會平滑地過渡到新的倍率，而不是逐級跳動；它會以滑鼠游標所在的確切位置為中心縮放，讓您注視的內容保持不動；當游標在螢幕中央區域移動時，畫面會保持穩定。它沒有任何設定選項，並常駐於系統匣。在某些方面它也比 Windows Magnifier 更為受限：沒有語音功能、沒有色彩濾鏡，最高只能放大到 5×。關於平滑動態背後的原因，詳見為什麼平滑放大更容易跟隨。

使用 Low Vision Zoom

在 Windows 11 中要如何放大畫面？

Windows 內建放大鏡：按住 Windows key 並按 Plus 可放大，按 Minus 可縮小，按住 Windows key + Esc 可關閉。您也可以在設定 → 系統 → 顯示 → 縮放比例中永久放大所有內容，或在設定 → 輔助功能 → 文字大小中只放大文字。安裝 Low Vision Zoom 後，您可以按住 Ctrl 並滾動滑鼠滾輪，在 Windows 中任何地方平滑縮放；若沒有滑鼠滾輪，也可以使用 Ctrl + Alt + Plus / Minus。

有沒有可以用滑鼠滾輪縮放的放大鏡？

有的。Low Vision Zoom 可用 Ctrl + 滑鼠滾輪縮放：按住 Ctrl 並向前滾動滾輪可放大，向後滾動可縮小。縮放幅度與您轉動滾輪的程度成正比，因此您轉動多少、多快，畫面就縮放多少、多快，並會平滑過渡到新的倍率，同時保持以指標所在的位置為中心。Ctrl + Shift + 向下捲動可立即恢復正常大小。這是本應用程式設計上主要的使用方式。

Low Vision Zoom 可以搭配多台螢幕使用嗎？

可以。它會將整個 Windows 桌面視為一個連續的空間來放大，並在游標從一台螢幕移動到另一台螢幕時持續跟隨，而不是把每台螢幕分開處理。這與內建 Windows Magnifier 的全螢幕模式所採用的方式相同。

沒有滑鼠滾輪的筆記型電腦要如何縮放？

使用鍵盤即可。按住 Ctrl + Alt，再按 Plus 放大或 Minus 縮小；持續按住按鍵即可持續縮放。Ctrl + Alt + 0 可重設為正常大小。不需要滑鼠滾輪或外接滑鼠，因此本應用程式在僅有觸控板的筆記型電腦上也能使用。

在遊戲和全螢幕影片中也能使用嗎？

幾乎所有地方都能使用。Low Vision Zoom 會放大整個 Windows 桌面，因此適用於瀏覽器、電子郵件、文件、視窗中播放的影片，以及 Windows 殼層本身。例外情況是取得獨佔全螢幕控制權、繞過一般桌面的遊戲或應用程式；這類內容可能無法被放大。將這類遊戲改為視窗模式或無邊框視窗模式執行，即可恢復放大功能。

Low Vision Zoom 最多可以將畫面放大多少？

最高 5×，以半倍為單位遞增。這是刻意為這款小巧、舒適的縮放工具設下的上限，比內建 Windows Magnifier（最高 16×）或 ZoomText 等完整套件（最高 36×）都要低。如果您需要超過 5× 的放大倍率，Low Vision Zoom 就不是適合您的工具——比較頁面會為您指出放大倍率更高的選擇。
