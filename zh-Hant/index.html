為什麼更好用：您永遠不必重新尋找位置。

大多數放大鏡會突然跳動，每一次跳動都迫使您的視線停下來，重新尋找原本的位置。Low Vision Zoom 的畫面移動則是平順且連續的。

視線能自然跟隨的動態

當放大鏡的畫面瞬間跳動時，您的視線必須跳躍著追上它，重新找到原本在讀的內容。而在這裡，每一次變化都以每秒 60 幀的動畫呈現，讓您的視線能平滑地隨之移動，而不是追著畫面跑。

您的錨點永遠不變

畫面會以游標所在的確切位置為中心進行縮放，該位置在放大過程中保持固定，其餘畫面則圍繞它放大。您只需將游標指向重要的內容，就能自行選擇錨點。

同一個畫面，而非全新畫面

每一格畫面都只是前一格的些微變化，因此畫面看起來就像同一個頁面平順地放大，而不是一個新畫面取代舊畫面。沒有任何東西會突然消失，也就沒有東西需要重新尋找。

步調由您決定

縮放幅度與您的操作成正比：您捲動多少、多快，畫面就相應地放大多少、多快，並且可以在動作進行中隨時停止或反向操作。由您自己啟動的動作，正是您的視線能夠預期的動作。

閱讀時畫面靜止不動

當您的游標在螢幕中央移動時，畫面會完全靜止不動，只有在接近螢幕邊緣時才會平滑移動。閱讀時不會有持續的畫面漂移。

紮實的 Windows 技術基礎

建構於 Windows 本身的放大功能 API 之上，具備自有的每秒 60 幀動畫引擎。安裝程式經過簽署認證，放大畫面時點按位置依然準確，且一切運算皆在本機完成，不會有任何資料離開您的電腦。

專為 Windows 10 與 11（64 位元，x64）打造 · 獨立安裝程式，無需另外下載其他項目 · 目前尚不支援 Windows on ARM。

小知識：視覺研究人員將這種現象稱為變化盲視：當畫面在視覺中斷的瞬間發生變化時，很容易讓人錯過移動的內容，進而失去原本追蹤的位置。畫面跳動的放大鏡，等於整天不斷重現這種中斷；而畫面平滑移動的放大鏡，則不會讓視線有任何機會迷失位置。
